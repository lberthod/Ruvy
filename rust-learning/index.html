Leçon 1

Hello World ✅

Concepts

  • Point d'entrée: fn main()
  • Macros: println!
  • Syntaxe de base avec {}

Code d'exemple

fn main() {
    println!("Hello, World!");

    let name = "Rust";
    println!("Je suis {}", name);
}

Résultat

Hello, World!
Je suis Rust

Points clés

  • fn main() = point d'entrée du programme
  • println! = affichage avec nouvelle ligne
  • {} = placeholder pour les variables
  • Terminer les instructions par ;
Leçon 2

Variables & Types ✅

Immuabilité par défaut

let x = 5;        // Immuable (par défaut)
// x = 6;         // ❌ Erreur!

let mut y = 10;   // Mutable
y = 20;           // ✅ OK

Types primitifs

Type Exemple Description
i32 42 Entier signé 32-bit
u64 100 Entier non-signé 64-bit
f64 3.14 Flottant 64-bit
bool true Booléen
char 'R' Caractère Unicode
String "Hello" Chaîne propriétaire

Collections

// Array (taille fixe)
let arr = [1, 2, 3, 4, 5];

// Vector (taille dynamique)
let mut vec = vec![1, 2, 3];
vec.push(4);

// Tuple
let tuple = (42, 3.14, true);

À retenir

  • Les variables sont immuables par défaut
  • String vs &str (propriétaire vs référence)
  • Rust infère automatiquement les types
Leçon 3

Fonctions ✅

Syntaxe de base

fn add(a: i32, b: i32) -> i32 {
    a + b  // Pas de ; = return implicite
}

fn main() {
    let result = add(10, 20);
    println!("{}", result);  // 30
}

Retours multiples

fn arithmetic(a: i32, b: i32) -> (i32, i32) {
    (a + b, a * b)  // Retourner un tuple
}

let (sum, product) = arithmetic(5, 6);
println!("Somme: {}, Produit: {}", sum, product);

Points clés

  • Les paramètres doivent avoir un type explicite
  • Le dernier expression sans ; est retourné
  • Les fonctions peuvent retourner des tuples
Leçon 4

Contrôle de Flux ✅

If / Else

if number > 0 {
    println!("Positif");
} else if number < 0 {
    println!("Négatif");
} else {
    println!("Zéro");
}

Boucles

// While
while x < 10 {
    x += 1;
}

// For
for i in 0..=5 {  // 0 à 5 inclus
    println!("{}", i);
}

Match (Pattern Matching)

match number {
    1 => println!("Un"),
    2 | 3 => println!("Deux ou trois"),
    4..=10 => println!("Entre 4 et 10"),
    _ => println!("Autre"),
}

Points clés

  • if peut retourner une valeur
  • for i in 0..5 = exclusif (0 à 4)
  • for i in 0..=5 = inclusif (0 à 5)
  • match traite tous les cas possibles
Leçon 5

Ownership 🔑 ✅

⚠️ LE CONCEPT CLÉ DE RUST!
Ce concept définit Rust. Prends le temps de le comprendre!

Les 3 Règles

  1. Chaque valeur a UN propriétaire unique
  2. Quand le propriétaire sort du scope, la valeur est supprimée
  3. On peut emprunter sans transférer la propriété

Move (Déplacement)

let s1 = String::from("Hello");
let s2 = s1;  // s1 est DÉPLACÉ vers s2
// println!("{}", s1);  // ❌ ERREUR! s1 n'existe plus
println!("{}", s2);     // ✅ OK

Borrowing (Emprunt)

// Emprunt immutable
let s = String::from("Hello");
let r1 = &s;  // Lecture
let r2 = &s;  // OK: plusieurs emprunts
println!("{}, {}", r1, r2);  // OK

// Emprunt mutable
let mut s = String::from("Hello");
let r = &mut s;  // Modification
r.push_str(" World");
// let r2 = &mut s;  // ❌ ERREUR! 1 seul emprunt mutable

Résumé

  • & = emprunt immutable (lecture)
  • &mut = emprunt mutable (modification)
  • Plusieurs emprunts immuables OK
  • UN SEUL emprunt mutable
  • Rust garantit aucun data race!
Leçon 6

Structs & Enums ✅

Structs (Structures)

struct Person {
    name: String,
    age: u8,
}

impl Person {
    fn display(&self) {
        println!("{}", self.name);
    }
}

let person = Person {
    name: String::from("Alice"),
    age: 30,
};
person.display();

Enums (Énumérations)

enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Text(String),
}

match message {
    Message::Quit => println!("Bye"),
    Message::Move { x, y } => println!("({}, {})", x, y),
    Message::Text(s) => println!("{}", s),
}

Points clés

  • Structs groupent les données
  • Impl ajoute les méthodes
  • &self = lecture, &mut self = modification
  • Enums ont des variantes avec pattern matching
Leçon 7

Gestion des Erreurs ✅

Option<T> (Valeur optionnelle)

let maybe: Option = Some(42);
match maybe {
    Some(value) => println!("{}", value),
    None => println!("Aucune valeur"),
}

// Raccourci
if let Some(value) = maybe {
    println!("{}", value);
}

Result<T, E> (Succès ou Erreur)

fn divide(a: i32, b: i32) -> Result {
    if b == 0 {
        Err(String::from("Division par zéro"))
    } else {
        Ok(a / b)
    }
}

match divide(10, 2) {
    Ok(result) => println!("{}", result),
    Err(e) => println!("Error: {}", e),
}

? Operator (Propagation d'erreur)

fn read_file() -> Result {
    let mut file = File::open("test.txt")?;
    let mut contents = String::new();
    file.read_to_string(&mut contents)?;
    Ok(contents)
}

À retenir

  • Option = Some(T) ou None
  • Result = Ok(T) ou Err(E)
  • unwrap() panique si None/Err
  • ? propage l'erreur automatiquement
  • Pas d'exceptions, gestion explicite!
