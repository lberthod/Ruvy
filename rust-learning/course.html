Leçon 1

Hello World ✅

Concepts

  • fn main() - Point d'entrée
  • println! - Affichage
  • {} - Placeholder

Code

fn main() {
    println!("Hello, World!");

    let name = "Rust";
    println!("Je suis {}", name);
}

Résultat

Hello, World!
Je suis Rust
💡 À retenir:
  • fn = fonction
  • println! = macro d'affichage
  • ; termine chaque instruction
Leçon 2

Variables & Types ✅

Immuabilité par défaut

let x = 5;       // Immuable (défaut)
// x = 6;         // ❌ Erreur!

let mut y = 10;  // Mutable
y = 20;          // ✅ OK

Types primitifs

Type Exemple
i32 42
f64 3.14
bool true
String "Hello"

Collections

let array = [1, 2, 3];           // Array
let vec = vec![1, 2, 3];          // Vector
let tuple = (42, "hi", true);     // Tuple
⚠️ Point clé: Les variables sont immuables par défaut pour éviter les bugs!
Leçon 3

Fonctions ✅

Syntaxe de base

fn add(a: i32, b: i32) -> i32 {
    a + b  // Pas de ; = return
}

fn main() {
    println!("{}", add(10, 20));  // 30
}

Retours multiples

fn arithmetic(a: i32, b: i32) -> (i32, i32) {
    (a + b, a * b)
}

let (sum, prod) = arithmetic(5, 6);
println!("Somme: {}, Produit: {}", sum, prod);
💡 À retenir:
  • Les paramètres ont un type explicite
  • Pas de ; = return implicite
  • Peut retourner des tuples
Leçon 4

Contrôle de Flux ✅

If / Else

if x > 0 {
    println!("Positif");
} else if x < 0 {
    println!("Négatif");
} else {
    println!("Zéro");
}

Boucles

for i in 0..=5 {      // 0 à 5
    println!("{}", i);
}

while x < 10 {
    x += 1;
}

Match

match number {
    1 => println!("Un"),
    2..=10 => println!("2 à 10"),
    _ => println!("Autre"),
}
💡 À retenir:
  • if est une expression
  • 0..5 = exclusif (0 à 4)
  • 0..=5 = inclusif (0 à 5)
  • match traite tous les cas
Leçon 5

Ownership 🔑 ✅

⚠️ LE CONCEPT CLÉ DE RUST!

C'est ce qui rend Rust spécial. Comprendre ownership = comprendre Rust!

Les 3 Règles

  1. Chaque valeur a UN propriétaire
  2. Quand le propriétaire disparaît, la valeur aussi
  3. On peut emprunter sans posséder

Move (Déplacement)

let s1 = String::from("Hello");
let s2 = s1;  // s1 est DÉPLACÉ!
// println!("{}", s1);  // ❌ ERREUR!
println!("{}", s2);     // ✅ OK

Borrowing (Emprunt)

let s = String::from("Hello");
let r1 = &s;  // Emprunt (lecture)
let r2 = &s;  // OK: plusieurs lectures
println!("{}, {}", r1, r2);  // OK

// Modification
let mut s = String::from("Hello");
let r = &mut s;  // UN SEUL emprunt mutable!
r.push_str(" World");
✅ Résumé:
  • & = emprunt (lecture)
  • &mut = emprunt (modification)
  • Plusieurs emprunts immuables OK
  • UN SEUL emprunt mutable
Leçon 6

Structs & Enums ✅

Structs

struct Person {
    name: String,
    age: u8,
}

impl Person {
    fn display(&self) {
        println!("{}", self.name);
    }
}

let p = Person {
    name: String::from("Alice"),
    age: 30,
};
p.display();

Enums

enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Text(String),
}

match message {
    Message::Quit => println!("Bye"),
    Message::Move { x, y } => println!("({}, {})", x, y),
    Message::Text(s) => println!("{}", s),
}
💡 À retenir:
  • Structs groupent des données
  • impl ajoute des méthodes
  • &self = lecture, &mut self = modification
  • Enums avec pattern matching
Leçon 7

Gestion des Erreurs ✅

Option<T>

let maybe: Option = Some(42);
match maybe {
    Some(x) => println!("{}", x),
    None => println!("Rien"),
}

if let Some(x) = maybe {
    println!("{}", x);
}

Result<T, E>

fn divide(a: i32, b: i32) -> Result {
    if b == 0 {
        Err(String::from("Division par zéro"))
    } else {
        Ok(a / b)
    }
}

match divide(10, 2) {
    Ok(r) => println!("{}", r),
    Err(e) => println!("Error: {}", e),
}

? Operator

fn read_file() -> Result {
    let mut file = File::open("test.txt")?;
    let mut contents = String::new();
    file.read_to_string(&mut contents)?;
    Ok(contents)
}
✅ À retenir:
  • Option = Some(T) ou None
  • Result = Ok(T) ou Err(E)
  • ? = propagation d'erreur
  • Pas d'exceptions, gestion explicite!
